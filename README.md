# Basalt Home extension catalog

Official declarative extension catalog for Basalt Home, published by sebi.digital.

The version1 index is at `https://raw.githubusercontent.com/DarveenDE/basalt-home-catalog/main/v1/index.json`. The initial catalog contains the signed German language extension, version3. Package identity, exact byte hash and update proof are recorded in the index. The language package contains its own public signing key; the application assigns official status using its independently pinned source/key.
