# Basalt Home extension catalog

Official declarative extension catalog for Basalt Home, published by sebi.digital.

The version1 index is at `https://raw.githubusercontent.com/DarveenDE/basalt-home-catalog/main/v1/index.json`. It offers the signed German language extension, version4, at `v1/german-v4.basalt` for Basalt application version code 14 or newer. The initially published version3 artifact remains byte-for-byte unchanged at `v1/german.basalt`, so previously cached version3 catalog entries still resolve to their original bytes. The current index does not offer version3 to older clients.

Package identity, exact byte hash and update proof are recorded in the index. The language package contains its own public signing key; the application assigns official status using its independently pinned source/key.
